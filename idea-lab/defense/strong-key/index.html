The four rules pros use

1. Long. Aim for a passphrase: a few random words, like river-purple-engine-cloud.
2. Unpredictable. No real names, birthdays, or common words. The guesser knows those.
3. Different everywhere. One password per site. If one leaks, the rest stay safe.
4. Let a tool remember. A password manager makes and stores long ones, so you do not have to.

✅ This is what security teams actually recommend now: length over squiggles, and never a password that has shown up in a leak.
